# FastAPI Time Series Application

This project is a FastAPI application designed to handle time series data using a PostgreSQL database. It provides a RESTful API for creating, reading, updating, and deleting time series records.

## Project Structure

```
fastapi-timeseries-app
├── src
│   ├── main.py               # Entry point of the FastAPI application
│   ├── api
│   │   ├── __init__.py       # API module initialization
│   │   └── routes.py         # API routes for time series data
│   ├── models
│   │   ├── __init__.py       # Models module initialization
│   │   └── timeseries.py     # SQLAlchemy models for time series data
│   ├── schemas
│   │   ├── __init__.py       # Schemas module initialization
│   │   └── timeseries.py     # Pydantic schemas for validating time series data
│   ├── database
│   │   ├── __init__.py       # Database module initialization
│   │   └── connection.py      # Database connection logic
│   └── services
│       ├── __init__.py       # Services module initialization
│       └── timeseries_service.py # Business logic for time series data
├── migrations
│   └── init.sql              # SQL scripts for initializing the PostgreSQL database
├── requirements.txt           # Project dependencies
└── README.md                  # Project documentation
```

## Setup Instructions

1. **Clone the repository:**
   ```
   git clone <repository-url>
   cd fastapi-timeseries-app
   ```

2. **Create a virtual environment:**
   ```
   python -m venv venv
   source venv/bin/activate  # On Windows use `venv\Scripts\activate`
   ```

3. **Install dependencies:**
   ```
   pip install -r requirements.txt
   ```

4. **Set up the PostgreSQL database:**
   - Create a PostgreSQL database and user.
   - Update the database connection settings in `src/database/connection.py`.

5. **Run the database migrations:**
   - Execute the SQL scripts in `migrations/init.sql` to set up the database schema.

6. **Start the FastAPI application:**
   ```
   uvicorn src.main:app --reload
   ```

## Usage

- The API provides endpoints for managing time series data. You can use tools like Postman or curl to interact with the API.
- Refer to the API documentation generated by FastAPI at `http://127.0.0.1:8000/docs` for more details on available endpoints and request/response formats.
